“OpenAI‑compatible” isn't agent-ready.

Your server answers chat. But does it return real tool_calls instead of <tool_call> text? Enforce tool_choice? Stream tool arguments that parse? Respect a JSON schema? Keep <think> out of the answer?

toolsmoke tells you in one command, and measures how fast it is.
