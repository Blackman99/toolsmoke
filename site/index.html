the core mechanism

Where there's smoke, there's a broken parser.

The most common failure is invisible from the outside: the model emits a tool call, the server's parser misses it, and it ships as plain text. Scroll through the real case from the sample run.

1 request
POST /v1/chat/completions
{ "messages": [{"role": "user",
    "content": "What's the weather in Paris right now?"}],
  "tools": [get_weather, get_time],
  "tool_choice": "none" }
2 server response
"message": {
  "content": "<tool_call> {{"name": "get_weather"…",
  "tool_calls": none }
3 your agent

✗ no tool call to run · prints the markup to the user · or loops

4 toolsmoke

tools.choice_none FAIL 491ms
tool call leaked into content as text: '<tool_call> {{"name": "get_weather"…

  1. Ask without tools

    The probe sends a trivial question with tool_choice: "none", which is what agents send on the turn where they want a plain answer.

  2. The call leaks as text

    The chat template emits a tool call anyway. The parser doesn't recognise it, so <tool_call> markup lands in content and tool_calls stays empty. The HTTP status is still 200.

  3. Your agent breaks far away

    Nothing is structured, so nothing runs. The user sees raw markup, or the loop retries until it gives up. The stack trace points at your agent, not the server.

  4. toolsmoke catches it

    Tool probes scan every reply for tool-call markup (<tool_call>, [TOOL_CALLS], <function=, <|python_tag|> and more). The probe fails with a detail line that says exactly what leaked. This is the real result from the README run.

the checklist

31 probes. One verdict.

Trivial prompts, temperature: 0, deterministic checks. A failure means the serving stack is broken, not that the model is dumb. Lights show the sample run.

Tool calling

single, schema-valid args, parallel with distinct ids, tool_choice none / required / named, markup leaks, tool-result round trips, streamed deltas

Basics

models list, system prompt, multi-turn memory, stop sequences, max_tokens + finish_reason

Streaming

SSE deltas, [DONE], finish_reason, stream_options.include_usage

Structured output

json_object mode and strict json_schema, validated

Reasoning

thinking arrives in reasoning_content, not as <think> in the answer

Errors

unknown model, malformed request, bad key → clean 4xx, not 500 or a silent 200

Anthropic Messages

/v1/messages, event stream sequence, tool_use, tool_result (opt-in)

Performance

median time-to-first-token and decode tokens/sec, with optional hard gates

Verdict sample run

NOT AGENT‑READY · exit 1

Exit code 0 when nothing fails, 1 on failures (or warnings with --strict), 2 if the endpoint is unreachable.
